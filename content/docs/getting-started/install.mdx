Download the installer for your computer. Yukibana then shows you how to
install it.

<Downloads />

On a Mac, the Apple silicon build is for Macs with an M1 chip or later, the
Intel build for older Macs. If you are not sure, open the Apple menu ›
**About This Mac**: it says **Chip** on Apple silicon and **Processor** on Intel.

On Linux, the AppImage runs on any distribution; the `.deb` is for Debian,
Ubuntu and the distributions based on them.

## Languages

Yukibana ships with what a course needs to build, run and test its projects.
Course projects currently declare one of two kinds:

- **Scala** with sbt (`scala-sbt`), with the Metals language server;
- **Rust** with Cargo (`rust-cargo`).

Because Yukibana runs VS Code extensions, another language is a matter of
bundling the right extension and toolchain. Tell us which ones your course needs.
