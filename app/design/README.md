# Yukibana's design system, copied

`tokens.css` and `base.css` are copies of `packages/design/css/` in the Yukibana repository (`@yukibana/design`, at
commit edf4e66). This site lives in its own repository, so it copies them instead of depending on the package, as
Light does. Do not edit them here: change the package, then copy both files again.

The package's README holds every decision and why. What this site adds on top is in `app/app.css` (Fumadocs' colours
mapped onto the tokens) and the components in `app/components/`.
